# 개인별 전술 전체 조회

HTTP 메서드: GET
HTTP 상태코드: 200 Ok, 401 Unauthorized, 403 Forbidden, 404 Not Found, 500 Server Error
URL Path (https:// 없으면 FE와 BE 인스턴스 주소): /api/v1/matches/{matchId}/tactics/players
버전: V1
분류: Tactic
엑세스 토큰 필요: O

# Request

## Headers

- `Content-Type: application/json`
- `Accept: application/json`
- `Authorization: Bearer {accessToken}`

## Body

없음

# Response

## 200 OK

팀원 누구나 조회 가능. 해당 경기에 등록된 전체 개인 전술 배열을 반환. 없으면 빈 배열.

```json
[
  {
    "tacticId": 502,
    "matchId": 1,
    "scope": "player",
    "playerId": 9,
    "content": "전방 압박 위주로 운영. 빌드업 시 CDM 두 명이 수비 밸런스 유지.",
    "updatedAt": "2025-07-14T09:00:00"
  },
  {
    "tacticId": 503,
    "matchId": 1,
    "scope": "player",
    "playerId": 12,
    "content": "측면 돌파 후 얼리크로스 위주.",
    "updatedAt": "2025-07-14T09:00:00"
  }
]
```

## 401 Unauthorized

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "인증이 필요합니다."
  }
}
```

## 403 Forbidden

```json
{
  "error": {
    "code": "FORBIDDEN",
    "message": "해당 팀에 접근 권한이 없습니다."
  }
}
```

## 404 Not Found

```json
{
  "error": {
    "code": "MATCH_NOT_FOUND",
    "message": "존재하지 않는 경기입니다."
  }
}
```

## 500 Internal Server Error

```json
{
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "서버 내부에 오류가 발생했습니다."
  }
}
```
