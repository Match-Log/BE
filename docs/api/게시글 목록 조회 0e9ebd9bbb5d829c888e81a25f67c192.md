# 게시글 목록 조회

HTTP 메서드: GET
HTTP 상태코드: 200 Ok, 401 Unauthorized, 403 Forbidden, 500 Server Error
URL Path (https:// 없으면 FE와 BE 인스턴스 주소): /api/v1/boards?teamId={teamId}
버전: V1
분류: Board
엑세스 토큰 필요: O

# Request

## Headers

- `Content-Type: application/json`
- `Accept: application/json`
- `Authorization: Bearer {accessToken}`

Body 없음.

예시: `GET /api/v1/boards?teamId=1`

| 파라미터 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| teamId | bigint | ✅ | 팀 ID (쿼리 파라미터) |

# Response

## 200 OK

```json
[
  {
    "boardId": 1,
    "teamId": 1,
    "playerId": 2,
    "playerName": "김감독",
    "title": "7/14 vs 서울 드래곤즈 참석 투표",
    "matchId": 1,
    "createdAt": "2025-07-10T00:00:00"
  }
]
```

## 401 Unauthorized

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "인증이 필요합니다."
  }
}
```

## 403 Forbidden

```json
{
  "error": {
    "code": "FORBIDDEN",
    "message": "해당 팀에 접근 권한이 없습니다."
  }
}
```

## 500 Internal Server Error

```json
{
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "서버 내부에 오류가 발생했습니다."
  }
}
```
