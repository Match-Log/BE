# 게시글 수정

HTTP 메서드: PATCH
HTTP 상태코드: 200 Ok, 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found, 500 Server Error
URL Path (https:// 없으면 FE와 BE 인스턴스 주소): /api/v1/boards/{boardId}
버전: V1
분류: Board
엑세스 토큰 필요: O

# Request

## Headers

- `Content-Type: application/json`
- `Accept: application/json`
- `Authorization: Bearer {accessToken}`

## Body

```json
{
  "title": "7/14 vs 서울 드래곤즈 참석 투표 (수정)",
  "content": "이번 경기 참석 여부를 확인해주세요. 마감: 7/13 자정"
}
```

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| title | string | ❌ | 제목 |
| content | string | ❌ | 내용 |

# Response

## 200 OK

```json
{
  "boardId": 1,
  "title": "7/14 vs 서울 드래곤즈 참석 투표 (수정)",
  "content": "이번 경기 참석 여부를 확인해주세요. 마감: 7/13 자정",
  "updatedAt": "2025-07-11T00:00:00"
}
```

## 400 Bad Request

```json
{
  "error": {
    "code": "INVALID_REQUEST_BODY",
    "message": "요청 값이 올바르지 않습니다."
  }
}
```

## 401 Unauthorized

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "인증이 필요합니다."
  }
}
```

## 403 Forbidden

```json
{
  "error": {
    "code": "FORBIDDEN",
    "message": "게시글 수정 권한이 없습니다. (작성자 또는 MANAGER만 가능)"
  }
}
```

## 404 Not Found

```json
{
  "error": {
    "code": "BOARD_NOT_FOUND",
    "message": "존재하지 않는 게시글입니다."
  }
}
```

## 500 Internal Server Error

```json
{
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "서버 내부에 오류가 발생했습니다."
  }
}
```
