# 게시글 작성

HTTP 메서드: POST
HTTP 상태코드: 201 Created, 400 Bad Request, 401 Unauthorized, 403 Forbidden, 500 Server Error
URL Path (https:// 없으면 FE와 BE 인스턴스 주소): /api/v1/boards
버전: V1
분류: Board
엑세스 토큰 필요: O

# Request

## Headers

- `Content-Type: application/json`
- `Accept: application/json`
- `Authorization: Bearer {accessToken}`

## Body

```json
{
  "teamId": 1,
  "documentType": "NOTE",
  "title": "6월 훈련 일정 공유",
  "content": "이번 달 훈련 일정입니다.",
  "isExpendedDocument": false
}
```

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| teamId | bigint | ✅ | 팀 ID |
| documentType | string | ✅ | NOTE만 가능 (VOTE는 경기 생성 시 자동 생성) |
| title | string | ✅ | 제목 · 최대 200자 |
| content | string | ✅ | 내용 |
| isExpendedDocument | boolean | ❌ | 게시판 상단 고정 여부 (기본값: false) |

VOTE 타입은 경기 생성 시 서버가 자동으로 생성하므로 직접 작성 불가.

# Response

## 201 Created

```json
{
  "boardId": 1,
  "teamId": 1,
  "playerId": 2,
  "documentType": "NOTE",
  "title": "6월 훈련 일정 공유",
  "content": "이번 달 훈련 일정입니다.",
  "isExpendedDocument": false,
  "matchId": null,
  "createdAt": "2025-07-10T00:00:00"
}
```

## 400 Bad Request

```json
{
  "error": {
    "code": "INVALID_REQUEST_BODY",
    "message": "요청 값이 올바르지 않습니다."
  }
}
```

## 401 Unauthorized

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "인증이 필요합니다."
  }
}
```

## 403 Forbidden

```json
{
  "error": {
    "code": "FORBIDDEN",
    "message": "게시글 작성 권한이 없습니다. (MANAGER만 가능)"
  }
}
```

## 500 Internal Server Error

```json
{
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "서버 내부에 오류가 발생했습니다."
  }
}
```
