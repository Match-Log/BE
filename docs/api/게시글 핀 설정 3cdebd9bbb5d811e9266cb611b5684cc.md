# 게시글 핀 설정

HTTP 메서드: PATCH
HTTP 상태코드: 200 OK, 401 Unauthorized, 403 Forbidden, 404 Not Found, 500 Server Error
URL Path (https:// 없으면 FE와 BE 인스턴스 주소): /api/v1/boards/{boardId}/pin
버전: V1
분류: Board
엑세스 토큰 필요: O

# Request

## Headers

- `Content-Type: application/json`
- `Accept: application/json`
- `Authorization: Bearer {accessToken}`

Body 없음.

# Response

## 200 OK

```json
{
  "boardId": 1,
  "isPinned": true,
  "updatedAt": "2025-07-11T00:00:00"
}
```

## 401 Unauthorized

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "인증이 필요합니다."
  }
}
```

## 403 Forbidden

```json
{
  "error": {
    "code": "FORBIDDEN",
    "message": "핀 설정 권한이 없습니다. (MANAGER만 가능)"
  }
}
```

## 404 Not Found

```json
{
  "error": {
    "code": "BOARD_NOT_FOUND",
    "message": "존재하지 않는 게시글입니다."
  }
}
```

## 500 Internal Server Error

```json
{
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "서버 내부에 오류가 발생했습니다."
  }
}
```
