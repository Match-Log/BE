# 경기 수정

HTTP 메서드: PATCH
HTTP 상태코드: 200 Ok, 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found, 500 Server Error
URL Path (https:// 없으면 FE와 BE 인스턴스 주소): /api/v1/matches/{matchId}
버전: V1
분류: Match
엑세스 토큰 필요: O

# Request

## Headers

- `Content-Type: application/json`
- `Accept: application/json`
- `Authorization: Bearer {accessToken}`

## Body

```json
{
  "opponent": "서울 드래곤즈",
  "matchDate": "2025-07-14T07:00:00",
  "location": "한강공원 풋살장",
  "homeAway": "HOME",
  "matchType": "SOCCER",
  "scoreHome": 3,
  "scoreAway": 1,
  "isFinished": true
}
```

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| opponent | string | ❌ | 상대팀 이름 |
| matchDate | datetime | ❌ | 경기 날짜/시간 |
| location | string | ❌ | 경기 장소 |
| homeAway | string | ❌ | HOME / AWAY |
| matchType | string | ❌ | SOCCER / FOOTBALL |
| scoreHome | int | ❌ | 홈팀 스코어 |
| scoreAway | int | ❌ | 어웨이팀 스코어 |
| isFinished | boolean | ❌ | 경기 완료 여부 |

# Response

## 200 OK

```json
{
  "matchId": 1,
  "opponent": "서울 드래곤즈",
  "matchDate": "2025-07-14T07:00:00",
  "finished": true,
  "scoreHome": 3,
  "scoreAway": 1,
  "updatedAt": "2025-07-14T09:00:00"
}
```

## 400 Bad Request

```json
{
  "error": {
    "code": "INVALID_REQUEST_BODY",
    "message": "요청 값이 올바르지 않습니다."
  }
}
```

## 401 Unauthorized

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "인증이 필요합니다."
  }
}
```

## 403 Forbidden

```json
{
  "error": {
    "code": "FORBIDDEN",
    "message": "경기 수정 권한이 없습니다. (MANAGER만 가능)"
  }
}
```

## 404 Not Found

```json
{
  "error": {
    "code": "MATCH_NOT_FOUND",
    "message": "존재하지 않는 경기입니다."
  }
}
```

## 500 Internal Server Error

```json
{
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "서버 내부에 오류가 발생했습니다."
  }
}
```
