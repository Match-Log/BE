# 경기 수정

HTTP 메서드: PATCH
HTTP 상태코드: 200 Ok, 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found, 409 Conflict, 500 Server Error
URL Path (https:// 없으면 FE와 BE 인스턴스 주소): /api/v1/matches/{matchId}
버전: V1
분류: Match
엑세스 토큰 필요: O

# Request

## Headers

- `Content-Type: application/json`
- `Accept: application/json`
- `Authorization: Bearer {accessToken}`

## Body

```json
{
  "opponent": "서울 드래곤즈",
  "matchDate": "2025-07-14T07:00:00",
  "location": "한강공원 풋살장",
  "homeAway": "HOME",
  "matchType": "SOCCER",
  "scoreHome": 3,
  "scoreAway": 1,
  "isFinished": true
}
```

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| opponent | string | ❌ | 상대팀 이름 |
| matchDate | datetime | ❌ | 경기 날짜/시간 |
| location | string | ❌ | 경기 장소 |
| homeAway | string | ❌ | HOME / AWAY |
| matchType | string | ❌ | SOCCER / FOOTBALL |
| scoreHome | int | ❌ | 홈팀 스코어 (종료 시 필수, 종료 후 정정 가능) |
| scoreAway | int | ❌ | 어웨이팀 스코어 (종료 시 필수, 종료 후 정정 가능) |
| isFinished | boolean | ❌ | `true`면 경기 종료. 킥오프 시각(matchDate) 이후에만 가능하며 scoreHome·scoreAway 필요 |

- 종료된 경기는 opponent, matchDate, location, homeAway, matchType 을 수정할 수 없습니다. (스코어·메모는 수정 가능)
- 종료되지 않은 경기에 isFinished 없이 스코어만 보낼 수 없습니다.

# Response

## 200 OK

```json
{
  "matchId": 1,
  "opponent": "서울 드래곤즈",
  "matchDate": "2025-07-14T07:00:00",
  "finished": true,
  "scoreHome": 3,
  "scoreAway": 1,
  "updatedAt": "2025-07-14T09:00:00"
}
```

## 400 Bad Request

```json
{
  "error": {
    "code": "INVALID_REQUEST_BODY",
    "message": "요청 값이 올바르지 않습니다."
  }
}
```

```json
{
  "error": {
    "code": "MATCH_SCORE_REQUIRED",
    "message": "경기를 종료하려면 홈/어웨이 스코어를 모두 입력해야 합니다."
  }
}
```

## 401 Unauthorized

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "인증이 필요합니다."
  }
}
```

```json
{

    "code": "FORBIDDEN",
```

```json
{
  "error": {

  }

```

```json
    "message": "경기 시작 전에는 종료할 수 없습니다."

```

```json
{

```

```json
{

```
