# 내 선수 정보 조회

HTTP 메서드: GET
HTTP 상태코드: 200 Ok, 401 Unauthorized, 404 Not Found, 500 Server Error
URL Path (https:// 없으면 FE와 BE 인스턴스 주소): /api/v1/players/me
버전: V1
분류: Player
엑세스 토큰 필요: O

# Request

## Headers

- `Content-Type: application/json`
- `Accept: application/json`
- `Authorization: Bearer {accessToken}`

## Body

없음

# Response

## 200 OK

```json
{
  "playerId": 1,
  "userId": 1,
  "birthDate": "1995-03-12",
  "height": 178,
  "weight": 72,
  "preferredFoot": "RIGHT",
  "career": "AMATEUR",
  "yearsOfExperience": 5,
  "preferredPosition": "CM",
  "subPosition": "CB",
  "createdAt": "2025-07-14T09:00:00"
}
```

## 401 Unauthorized

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "인증이 필요합니다."
  }
}
```

## 404 Not Found → 로그인한 사용자가 선수 등록을 하지 않은 경우

```json
{
  "error": {
    "code": "PLAYER_NOT_FOUND",
    "message": "존재하지 않는 선수입니다."
  }
}
```

## 500 Internal Server Error

```json
{
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "서버 내부에 오류가 발생했습니다."
  }
}
```
