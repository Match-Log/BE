# 내 팀 목록 조회

HTTP 메서드: GET
HTTP 상태코드: 200 Ok, 401 Unauthorized, 500 Server Error
URL Path (https:// 없으면 FE와 BE 인스턴스 주소): /api/v1/teams
버전: V1
분류: Team
엑세스 토큰 필요: O

# Request

## Headers

- `Content-Type: application/json`
- `Accept: application/json`
- `Authorization: Bearer {accessToken}`

Body 없음. JWT에서 userId 추출하여 소속 팀 목록 반환.
