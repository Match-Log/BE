# 댓글 작성

HTTP 메서드: POST
HTTP 상태코드: 201 Created, 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found, 500 Server Error
URL Path (https:// 없으면 FE와 BE 인스턴스 주소): /api/v1/boards/{boardId}/comments
버전: V1
분류: Comment
엑세스 토큰 필요: O

# Request

## Headers

- `Content-Type: application/json`
- `Accept: application/json`
- `Authorization: Bearer {accessToken}`

## Path Variable

| 파라미터 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| boardId | bigint | ✅ | 게시글 ID |

## Body

```json
{
  "content": "다음 훈련 때 뵙겠습니다!"
}
```

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| content | string | ✅ | 댓글 본문 |

# Response

## 201 Created

```json
{
  "commentId": 1,
  "boardId": 3,
  "playerId": 2,
  "playerName": "홍길동",
  "content": "다음 훈련 때 뵙겠습니다!",
  "createdAt": "2025-07-10T10:00:00",
  "updatedAt": "2025-07-10T10:00:00"
}
```

## 400 Bad Request

```json
{
  "error": {
    "code": "INVALID_REQUEST_BODY",
    "message": "요청 값이 올바르지 않습니다."
  }
}
```

## 401 Unauthorized

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "인증이 필요합니다."
  }
}
```

## 403 Forbidden

```json
{
  "error": {
    "code": "FORBIDDEN",
    "message": "해당 팀에 접근 권한이 없습니다."
  }
}
```

## 404 Not Found

```json
{
  "error": {
    "code": "BOARD_NOT_FOUND",
    "message": "존재하지 않는 게시글입니다."
  }
}
```

## 500 Internal Server Error

```json
{
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "서버 내부에 오류가 발생했습니다."
  }
}
```
