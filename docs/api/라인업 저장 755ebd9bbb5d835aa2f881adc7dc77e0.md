# 라인업 저장

HTTP 메서드: PUT
HTTP 상태코드: 200 Ok, 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found, 500 Server Error
URL Path (https:// 없으면 FE와 BE 인스턴스 주소): /api/v1/matches/{matchId}/lineup
버전: V1
분류: Lineup
엑세스 토큰 필요: O

# Request

## Headers

- `Content-Type: application/json`
- `Accept: application/json`
- `Authorization: Bearer {accessToken}`

## Body

```json
{
  "matchId": 1,
  "quarter": 1,
  "formation": "4-2-3-1",
  "spots": [
    { "playerId": 1,  "guestId": null, "position": "GK",  "isStarter": true },
    { "playerId": 2,  "guestId": null, "position": "LB",  "isStarter": true },
    { "playerId": 3,  "guestId": null, "position": "CB",  "isStarter": true },
    { "playerId": 4,  "guestId": null, "position": "CB",  "isStarter": true },
    { "playerId": 5,  "guestId": null, "position": "RB",  "isStarter": true },
    { "playerId": 6,  "guestId": null, "position": "CDM", "isStarter": true },
    { "playerId": 7,  "guestId": null, "position": "CDM", "isStarter": true },
    { "playerId": 8,  "guestId": null, "position": "LW",  "isStarter": true },
    { "playerId": 9,  "guestId": null, "position": "CAM", "isStarter": true },
    { "playerId": 10, "guestId": null, "position": "RW",  "isStarter": true },
    { "playerId": null, "guestId": 3,  "position": "ST",  "isStarter": true },
    { "playerId": 12, "guestId": null, "position": "SUB", "isStarter": false }
  ]
}
```

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| matchId | bigint | ✅ | 경기 ID |
| quarter | int | ✅ | 쿼터 (1 / 2 / 3 / 4) |
| formation | string | ✅ | 포메이션 (예: 4-2-3-1) |
| spots | array | ✅ | 선수 배치 목록 |
| spots.playerId | bigint | 조건부 | 팀 선수 ID — guestId와 둘 중 하나만 non-null |
| spots.guestId | bigint | 조건부 | 용병 ID (MATCH_GUEST.id) — playerId와 둘 중 하나만 non-null |
| spots.position | string | ✅ | GK / LB / CB / RB 등 |
| spots.isStarter | boolean | ✅ | true: 선발 / false: 후보 |

포메이션 분기는 MATCH.matchType 값을 기준으로 하므로 Request에서 별도 필드 없음.

있으면 수정, 없으면 생성 (Upsert 방식)
