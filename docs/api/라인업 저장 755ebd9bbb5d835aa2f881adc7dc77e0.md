# 라인업 저장

HTTP 메서드: PUT
HTTP 상태코드: 200 Ok, 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found, 500 Server Error
URL Path (https:// 없으면 FE와 BE 인스턴스 주소): /api/v1/matches/{matchId}/lineup
버전: V1
분류: Lineup
엑세스 토큰 필요: O

# Request

## Headers

- `Content-Type: application/json`
- `Accept: application/json`
- `Authorization: Bearer {accessToken}`

## Body

```json
{
  "matchId": 1,
  "quarter": 1,
  "formation": "4-2-3-1",
  "spots": [
    { "playerId": 1, "position": "GK", "isStarter": true },
    { "playerId": 2, "position": "LB", "isStarter": true },
    { "playerId": 3, "position": "CB", "isStarter": true },
    { "playerId": 4, "position": "CB", "isStarter": true },
    { "playerId": 5, "position": "RB", "isStarter": true },
    { "playerId": 6, "position": "CDM", "isStarter": true },
    { "playerId": 7, "position": "CDM", "isStarter": true },
    { "playerId": 8, "position": "LW", "isStarter": true },
    { "playerId": 9, "position": "CAM", "isStarter": true },
    { "playerId": 10, "position": "RW", "isStarter": true },
    { "playerId": 11, "position": "ST", "isStarter": true },
    { "playerId": 12, "position": "SUB", "isStarter": false }
  ]
}
```

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| matchId | bigint | ✅ | 경기 ID ([MATCH.id](http://MATCH.id)) |
| quarter | int | ✅ | 쿼터 (1 / 2 / 3 / 4) |
| formation | string | ✅ | 포메이션 (예: 4-2-3-1) |
| spots | array | ✅ | 선수 배치 목록 |
| spots.playerId | bigint | ✅ | 선수 ID ([PLAYER.id](http://PLAYER.id)) |
| spots.position | string | ✅ | GK / LB / CB / RB 등 |
| spots.isStarter | boolean | ✅ | true: 선발 / false: 후보 |

포메이션 분기는 MATCH.matchType 값을 기준으로 하므로 Request에서 별도 필드 없음.

있으면 수정, 없으면 생성 (Upsert 방식)

# Response

## 200 OK

```json
{
  "lineupId": 1,
  "matchId": 1,
  "quarter": 1,
  "formation": "4-2-3-1",
  "updatedAt": "2025-07-14T09:00:00"
}
```

## 400 Bad Request

```json
{
  "error": {
    "code": "INVALID_REQUEST_BODY",
    "message": "요청 값이 올바르지 않습니다."
  }
}
```

## 401 Unauthorized

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "인증이 필요합니다."
  }
}
```

## 403 Forbidden

```json
{
  "error": {
    "code": "FORBIDDEN",
    "message": "라인업 수정 권한이 없습니다. (MANAGER만 가능)"
  }
}
```

## 404 Not Found

```json
{
  "error": {
    "code": "MATCH_NOT_FOUND",
    "message": "존재하지 않는 경기입니다."
  }
}
```
