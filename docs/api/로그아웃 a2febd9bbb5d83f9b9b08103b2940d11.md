# 로그아웃

HTTP 메서드: POST
HTTP 상태코드: 204 No Content, 401 Unauthorized, 500 Server Error
URL Path (https:// 없으면 FE와 BE 인스턴스 주소): /api/v1/auth/logout
버전: V1
분류: Auth
엑세스 토큰 필요: O

# Request

## Headers

- `Content-Type: application/json`
- `Accept: application/json`
- `Authorization: Bearer {accessToken}`

Body 없음.

# Response

## 204 No Content

## 401 Unauthorized

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "인증이 필요합니다."
  }
}
```

## 500 Internal Server Error

```json
{
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "서버 내부에 오류가 발생했습니다."
  }
}
```
