# 로스터에서 제외

HTTP 메서드: DELETE
HTTP 상태코드: 204 No Content, 401 Unauthorized, 403 Forbidden, 404 Not Found, 409 Conflict, 500 Server Error
URL Path (https:// 없으면 FE와 BE 인스턴스 주소): /api/v1/teams/{teamId}/players/{playerId}
버전: V1
분류: Team
엑세스 토큰 필요: O

# Request

## Headers

- `Content-Type: application/json`
- `Accept: application/json`
- `Authorization: Bearer {accessToken}`

Body 없음.

# Response

## 204 No Content

본문 없음.

## 401 Unauthorized

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "인증이 필요합니다."
  }
}
```

## 403 Forbidden

```json
{
  "error": {
    "code": "FORBIDDEN",
    "message": "팀원 제외 권한이 없습니다. (MANAGER만 가능)"
  }
}
```

## 403 Forbidden → Service 검증

본인을 대상으로 제외 요청 시(탈퇴는 별도 API 사용)

```json
{
  "error": {
    "code": "FORBIDDEN",
    "message": "본인은 제외할 수 없습니다. 탈퇴 API를 사용하세요."
  }
}
```

## 409 Conflict → Service 검증

팀의 유일한 MANAGER를 제외하려는 경우

```json
{
  "error": {
    "code": "LAST_MANAGER_CANNOT_BE_REMOVED",
    "message": "팀의 마지막 MANAGER는 제외할 수 없습니다."
  }
}
```

## 404 Not Found

```json
{
  "error": {
    "code": "PARTICIPATION_NOT_FOUND",
    "message": "존재하지 않는 팀 참가 정보입니다."
  }
}
```

## 500 Internal Server Error

```json
{
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "서버 내부에 오류가 발생했습니다."
  }
}
```
