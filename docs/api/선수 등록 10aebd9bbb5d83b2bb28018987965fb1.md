# 선수 등록

HTTP 메서드: POST
URL Path (https:// 없으면 FE와 BE 인스턴스 주소): /api/v1/players
버전: V1
분류: Player

# Request

## Headers

- `Content-Type: application/json`
- `Accept: application/json`
- `Authorization: Bearer {accessToken}`

## Body

```json
{
  "birthDate": "1995-03-12",
  "height": 178,
  "weight": 72,
  "preferredFoot": "RIGHT",
  "career": "전 마포 유나이티드"
}
```

# Response

## 201 Created

```json
{
  "playerId": 1,
  "userId": 1,
  "birthDate": "1995-03-12",
  "height": 178,
  "weight": 72,
  "preferredFoot": "RIGHT",
  "career": "전 마포 유나이티드",
  "createdAt": "2025-07-14T09:00:00"
}
```

## 400 Bad Request

```json
{
  "error": {
    "code": "INVALID_REQUEST_BODY",
    "message": "요청 값이 올바르지 않습니다."
  }
}
```

## 401 Unauthorized

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "인증이 필요합니다."
  }
}
```

## 500 Internal Server Error

```json
{
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "서버 내부에 오류가 발생했습니다."
  }
}
```
