# 선수 등록

HTTP 메서드: POST
HTTP 상태코드: 201 Created, 400 Bad Request, 401 Unauthorized, 404 Not Found, 409 Conflict, 500 Server Error
URL Path (https:// 없으면 FE와 BE 인스턴스 주소): /api/v1/players
버전: V1
분류: Player
엑세스 토큰 필요: O

# Request

## Headers

- `Content-Type: application/json`
- `Accept: application/json`
- `Authorization: Bearer {accessToken}`

## Body

```json
{
  "birthDate": "1995-03-12",
  "height": 178,
  "weight": 72,
  "preferredFoot": "RIGHT",
  "career": "전 마포 유나이티드"
}
```

# Response

## 201 Created

```json
{
  "playerId": 1,
  "userId": 1,
  "birthDate": "1995-03-12",
  "height": 178,
  "weight": 72,
  "preferredFoot": "RIGHT",
  "career": "전 마포 유나이티드",
  "createdAt": "2025-07-14T09:00:00"
}
```

## 400 Bad Request

```json
{
  "error": {
    "code": "INVALID_REQUEST_BODY",
    "message": "요청 값이 올바르지 않습니다."
  }
}
```

## 401 Unauthorized

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "인증이 필요합니다."
  }
}
```

## 404 Not Found → Service 검증

토큰은 유효하지만 대상 유저가 이미 탈퇴 등으로 존재하지 않는 경우

```json
{
  "error": {
    "code": "USER_NOT_FOUND",
    "message": "존재하지 않는 유저입니다."
  }
}
```

## 409 Conflict → Service 검증

```json
{
  "error": {
    "code": "PLAYER_ALREADY_EXISTS",
    "message": "이미 선수 등록이 완료된 계정입니다."
  }
}
```

## 500 Internal Server Error

```json
{
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "서버 내부에 오류가 발생했습니다."
  }
}
```
