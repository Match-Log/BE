# 선수 스탯 저장

HTTP 메서드: PUT
HTTP 상태코드: 200 Ok, 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found, 500 Server Error
URL Path (https:// 없으면 FE와 BE 인스턴스 주소): /api/v1/matches/{matchId}/stats/players/{playerId}
버전: V1
분류: Stat
엑세스 토큰 필요: O

# Request

## Headers

- `Content-Type: application/json`
- `Accept: application/json`
- `Authorization: Bearer {accessToken}`

## Body

```json
{
  "goals": 2,
  "assists": 1,
  "shots": 5,
  "yellowCard": 0,
  "redCard": 0,
  "saves": null,
  "goalsConceded": null,
  "cleanSheet": null
}
```

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| goals | int | ❌ | 골 수 (기본값: 0) |
| assists | int | ❌ | 어시스트 수 (기본값: 0) |
| shots | int | ❌ | 슈팅 수 (기본값: 0) |
| yellowCard | int | ❌ | 경고 수 (기본값: 0) |
| redCard | int | ❌ | 퇴장 수 (기본값: 0) |
| saves | int | ❌ | 선방 수 (GK 전용 · nullable) |
| goalsConceded | int | ❌ | 실점 수 (GK 전용 · nullable) |
| cleanSheet | boolean | ❌ | 클린시트 여부 (GK 전용 · nullable) |

있으면 수정, 없으면 생성 (Upsert 방식)

# Response

## 200 OK

```json
{
  "matchId": 1,
  "playerId": 9,
  "goals": 2,
  "assists": 1,
  "shots": 5,
  "yellowCard": 0,
  "redCard": 0,
  "saves": null,
  "goalsConceded": null,
  "cleanSheet": null,
  "updatedAt": "2025-07-14T09:00:00"
}
```

## 400 Bad Request

```json
{
  "error": {
    "code": "INVALID_REQUEST_BODY",
    "message": "요청 값이 올바르지 않습니다."
  }
}
```

## 401 Unauthorized

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "인증이 필요합니다."
  }
}
```

## 403 Forbidden

```json
{
  "error": {
    "code": "FORBIDDEN",
    "message": "스탯 입력 권한이 없습니다. (MANAGER만 가능)"
  }
}
```

## 404 Not Found

```json
{
  "error": {
    "code": "MATCH_NOT_FOUND",
    "message": "존재하지 않는 경기입니다."
  }
}
```

## 500 Internal Server Error

```json

```
