# 선수 스탯 집계 조회 (월별/시즌)

HTTP 메서드: GET
HTTP 상태코드: 200 Ok, 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found, 500 Server Error
URL Path (https:// 없으면 FE와 BE 인스턴스 주소): /api/v1/teams/{teamId}/players/{playerId}/stats/summary?period={StatPeriod}&year={year}&month={month}
버전: V1
분류: Stat
엑세스 토큰 필요: O

경기당 스탯(`PLAYER_STAT`)과 개인 피드백 평점(`PERSONAL_FEEDBACK.rating`)을 기간별로 합산/평균한 프로필용 집계. 별도 저장 테이블 없이 매 요청마다 실시간 집계.

# Request

## Headers

- `Content-Type: application/json`
- `Accept: application/json`
- `Authorization: Bearer {accessToken}`

## Query Parameters

| 파라미터 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `period` | `StatPeriod` | ✅ | `MONTHLY` / `SEASON` |
| `year` | number | ✅ | 조회 연도 |
| `month` | number | `period=MONTHLY`일 때만 ✅ | 1~12. `period=SEASON`이면 무시됨(응답에도 null) |

시즌(`SEASON`)은 캘린더 연도(1/1~12/31) 기준.

Body 없음.

# Response

## 200 OK

```json
{
  "playerId": 9,
  "period": "MONTHLY",
  "year": 2026,
  "month": 9,
  "matchCount": 4,
  "goals": 2,
  "assists": 1,
  "saves": null,
  "cleanSheetCount": null,
  "mvpCount": 1,
  "averageRating": 7.5
}
```

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| matchCount | number | 해당 기간에 `PLAYER_STAT` row가 존재하는 경기 수 |
| goals / assists | number | 필드 플레이어 스탯 합계 |
| saves | number \| null | GK 세이브 합계. 한 번도 GK 스탯이 없으면 null |
| cleanSheetCount | number \| null | GK 클린시트 횟수. 한 번도 GK 스탯이 없으면 null |
| mvpCount | number | 해당 기간에 MVP(동점 포함)로 기록된 경기 수 |
| averageRating | number \| null | `PERSONAL_FEEDBACK.rating` 평균(1~10). 피드백이 없으면 null |

## 400 Bad Request

```json
{
  "error": {
    "code": "INVALID_REQUEST_BODY",
    "message": "period=MONTHLY일 때 month는 1~12 사이여야 합니다."
  }
}
```
