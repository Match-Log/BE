# 세트피스 역할 배정 저장

HTTP 메서드: PUT
HTTP 상태코드: 200 Ok, 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found, 500 Server Error
URL Path (https:// 없으면 FE와 BE 인스턴스 주소): /api/v1/teams/{teamId}/role-assignment
버전: V1
분류: Team
엑세스 토큰 필요: O

# Request

## Headers

- `Content-Type: application/json`
- `Accept: application/json`
- `Authorization: Bearer {accessToken}`

## Body

```json
{
  "captainParticipationId": 9,
  "pkTakerParticipationId": null,
  "ckLeftParticipationId": null,
  "ckRightParticipationId": 12,
  "fkLeftParticipationId": null,
  "fkRightParticipationId": null
}
```

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| captainParticipationId | long | ❌ | 주장으로 지정할 참가 정보 id · null이면 해제 |
| pkTakerParticipationId | long | ❌ | PK 키커로 지정할 참가 정보 id · null이면 해제 |
| ckLeftParticipationId | long | ❌ | CK 왼쪽 키커로 지정할 참가 정보 id · null이면 해제 |
| ckRightParticipationId | long | ❌ | CK 오른쪽 키커로 지정할 참가 정보 id · null이면 해제 |
| fkLeftParticipationId | long | ❌ | FK 왼쪽 키커로 지정할 참가 정보 id · null이면 해제 |
| fkRightParticipationId | long | ❌ | FK 오른쪽 키커로 지정할 참가 정보 id · null이면 해제 |

6개 슬롯을 한 번에 전체 교체하는 방식(PUT). 전달하지 않은 필드는 null로 간주되어 해당 역할이 해제됩니다.
같은 참가 정보를 여러 역할에 동시에 지정할 수 있습니다(예: 주장이 PK 키커 겸직).
지정하려는 참가 정보는 반드시 해당 팀 소속이어야 합니다.

# Response

## 200 OK

```json
{
  "teamId": 1,
  "captain": { "participationId": 9, "playerId": 9, "name": "임준혁" },
  "pkTaker": null,
  "ckLeft": null,
  "ckRight": { "participationId": 12, "playerId": 12, "name": "박서준" },
  "fkLeft": null,
  "fkRight": null,
  "updatedAt": "2025-03-01T00:00:00"
}
```

## 400 Bad Request

```json
{
  "error": {
    "code": "INVALID_REQUEST_BODY",
    "message": "요청 값이 올바르지 않습니다."
  }
}
```

## 401 Unauthorized

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "인증이 필요합니다."
  }
}
```

## 403 Forbidden

```json
{
  "error": {
    "code": "FORBIDDEN",
    "message": "세트피스 역할 지정 권한이 없습니다. (MANAGER만 가능)"
  }
}
```

## 404 Not Found → Service 검증

teamId 자체가 존재하지 않는 경우

```json
{
  "error": {
    "code": "TEAM_NOT_FOUND",
    "message": "존재하지 않는 팀입니다."
  }
}
```

지정하려는 participationId가 해당 팀 소속이 아니거나 존재하지 않는 경우

```json
{
  "error": {
    "code": "MEMBER_NOT_FOUND",
    "message": "해당 팀에 존재하지 않는 멤버입니다."
  }
}
```

## 500 Internal Server Error

```json
{
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "서버 내부에 오류가 발생했습니다."
  }
}
```
