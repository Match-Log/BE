# 용병 삭제

HTTP 메서드: DELETE
HTTP 상태코드: 204 No Content, 401 Unauthorized, 403 Forbidden, 404 Not Found, 500 Server Error
URL Path (https:// 없으면 FE와 BE 인스턴스 주소): /api/v1/matches/{matchId}/guests/{guestId}
버전: V1
분류: Lineup
엑세스 토큰 필요: O

# Request

## Headers

- `Authorization: Bearer {accessToken}`

Body 없음.

# Response

## 204 No Content

응답 Body 없음.

## 401 Unauthorized

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "인증이 필요합니다."
  }
}
```

## 403 Forbidden

```json
{
  "error": {
    "code": "FORBIDDEN",
    "message": "용병 삭제는 매니저만 할 수 있습니다."
  }
}
```

## 404 Not Found

```json
{
  "error": {
    "code": "GUEST_NOT_FOUND",
    "message": "존재하지 않는 용병입니다."
  }
}
```

```json
{
  "error": {
    "code": "MATCH_NOT_FOUND",
    "message": "존재하지 않는 경기입니다."
  }
}
```

## 500 Internal Server Error

```json
{
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "서버 내부에 오류가 발생했습니다."
  }
}
```
