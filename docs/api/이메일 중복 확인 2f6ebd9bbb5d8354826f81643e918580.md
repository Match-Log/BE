# 이메일 중복 확인

HTTP 메서드: GET
HTTP 상태코드: 200 Ok, 400 Bad Request, 409 Conflict, 500 Server Error
URL Path (https:// 없으면 FE와 BE 인스턴스 주소): /api/v1/auth/check-email?email={email}
버전: V1
분류: Auth
엑세스 토큰 필요: X

# Request

## Headers

- `Content-Type: application/json`
- `Accept: application/json`

## Query Parameter

| 파라미터 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| email | string | ✅ | 중복 확인할 이메일 주소 |

예시: `GET /api/v1/auth/check-email?email=user@example.com`

# Response

## 200 OK

```json
{
  "available": true
}
```

## 400 Bad Request

```json
{
  "error": {
    "code": "INVALID_REQUEST_BODY",
    "message": "이메일 형식이 올바르지 않습니다."
  }
}
```

## 409 Conflict

```json
{
  "error": {
    "code": "EMAIL_CONFLICT",
    "message": "이미 사용 중인 이메일입니다."
  }
}
```

## 500 Internal Server Error

```json
{
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "서버 내부에 오류가 발생했습니다."
  }
}
```
