# 전담 키커 지정

HTTP 메서드: PUT
HTTP 상태코드: 200 Ok, 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found, 500 Server Error
URL Path (https:// 없으면 FE와 BE 인스턴스 주소): /api/v1/teams/{teamId}/players/{playerId}/kicker
버전: V1
분류: Team
엑세스 토큰 필요: O

# Request

## Headers

- `Content-Type: application/json`
- `Accept: application/json`
- `Authorization: Bearer {accessToken}`

## Body

```json
{
  "isCaptain": true,
  "isPkTaker": false,
  "isFkRight": true,
  "isFkLeft": false,
  "isCkRight": false,
  "isCkLeft": false
}
```

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| isCaptain | boolean | ❌ | 주장 여부 |
| isPkTaker | boolean | ❌ | PK 키커 여부 |
| isFkRight | boolean | ❌ | FK 오른쪽 키커 여부 |
| isFkLeft | boolean | ❌ | FK 왼쪽 키커 여부 |
| isCkRight | boolean | ❌ | CK 오른쪽 키커 여부 |
| isCkLeft | boolean | ❌ | CK 왼쪽 키커 여부 |

있으면 수정, 없으면 생성 (Upsert 방식)

# Response

## 200 OK

```json
{
  "teamId": 1,
  "playerId": 9,
  "isCaptain": true,
  "isPkTaker": false,
  "isFkRight": true,
  "isFkLeft": false,
  "isCkRight": false,
  "isCkLeft": false,
  "updatedAt": "2025-03-01T00:00:00"
}
```

```json
{
  "error": {
    "code": "INVALID_REQUEST_BODY",
    "message": "요청 값이 올바르지 않습니다."
  }
}
```

    "code": "UNAUTHORIZED",
