# 전술 저장

HTTP 메서드: PUT
HTTP 상태코드: 200 Ok, 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found, 500 Server Error
URL Path (https:// 없으면 FE와 BE 인스턴스 주소): /api/v1/matches/{matchId}/tactics?scope={team | player}
- scope=team: /api/v1/matches/{matchId}/tactics?scope=team
- scope=player: /api/v1/matches/{matchId}/tactics?scope=player&playerId={playerId}  ← 전술 대상 선수 ID 필수
버전: V1
분류: Tactic
엑세스 토큰 필요: O

# Request

## Headers

- `Content-Type: application/json`
- `Accept: application/json`
- `Authorization: Bearer {accessToken}`

## Body

(scope = team )

```json
{ "content": "전방 압박 위주로 운영. 빌드업 시 CDM 두 명이 수비 밸런스 유지." }
```

(scope = player )

```json
{ "content": "전방 압박 위주로 운영. 빌드업 시 CDM 두 명이 수비 밸런스 유지." }
```

있으면 수정, 없으면 생성 (Upsert 방식)

# Response

## 200 OK

```json
{
  "tacticId": 501,
  "matchId": 1,
  "scope": "team",
  "playerId": null,
  "content": "전방 압박 위주로 운영. 빌드업 시 CDM 두 명이 수비 밸런스 유지.",
  "updatedAt": "2025-07-14T09:00:00"
}
```

(scope=player로 저장하면 `scope`, `playerId`, `content`가 그 값으로 채워져서 반환

## 400 Bad Request

```json
{
  "error": {
    "code": "INVALID_REQUEST_BODY",
    "message": "요청 값이 올바르지 않습니다."
  }
}
```

## 401 Unauthorized

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "인증이 필요합니다."
  }
}
```

## 403 Forbidden

```json
{
  "error": {
    "code": "FORBIDDEN",
    "message": "전술 작성 권한이 없습니다. (MANAGER만 가능)"
  }
}
```

## 404 Not Found

```json
{
  "error": {
    "code": "MATCH_NOT_FOUND",
    "message": "존재하지 않는 경기입니다."
  }
}
```
