# 참가 정보 수정 (역할/등번호/포지션)

HTTP 메서드: PATCH
HTTP 상태코드: 200 Ok, 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found, 500 Server Error
URL Path (https:// 없으면 FE와 BE 인스턴스 주소): /api/v1/teams/{teamId}/players/{playerId}
버전: V1
분류: Team
엑세스 토큰 필요: O

# Request

## Headers

- `Content-Type: application/json`
- `Accept: application/json`
- `Authorization: Bearer {accessToken}`

## Body

```json
{
  "role": "MANAGER",
  "number": 4,
  "mainPosition": "CB",
  "subPosition": null
}
```

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| role | string | ❌ | MANAGER | PLAYER |
| number | int | ❌ | 이 팀에서의 등번호 · null 입력 시 삭제 |
| mainPosition | string | ❌ | 이 팀에서의 주 포지션 · null 입력 시 삭제 |
| subPosition | string | ❌ | 이 팀에서의 부 포지션 · null 입력 시 삭제 |

전달된 필드만 반영됩니다 (부분 수정).

# Response

## 200 OK

```json
{
  "participationId": 1,
  "teamId": 1,
  "playerId": 9,
  "role": "MANAGER",
  "number": 4,
  "mainPosition": "CB",
  "subPosition": null,
  "updatedAt": "2025-07-14T09:00:00"
}
```

## 400 Bad Request

```json
{
  "error": {
    "code": "INVALID_REQUEST_BODY",
    "message": "요청 값이 올바르지 않습니다."
  }
}
```

## 401 Unauthorized

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "인증이 필요합니다."
  }
}
```

## 403 Forbidden

```json
{
  "error": {
    "code": "FORBIDDEN",
    "message": "참가 정보 수정 권한이 없습니다. (MANAGER만 가능)"
  }
}
```

## 404 Not Found

```json
{
  "error": {
    "code": "PARTICIPATION_NOT_FOUND",
    "message": "존재하지 않는 팀 참가 정보입니다."
  }
}
```
