# 참석 투표 현황 조회

HTTP 메서드: GET
HTTP 상태코드: 200 Ok, 401 Unauthorized, 403 Forbidden, 404 Not Found, 500 Server Error
URL Path (https:// 없으면 FE와 BE 인스턴스 주소): /api/v1/matches/{matchId}/votes?status={VoteStatus}
버전: V1
분류: Match
엑세스 토큰 필요: O

# Request

## Headers

- `Content-Type: application/json`
- `Accept: application/json`
- `Authorization: Bearer {accessToken}`

## Query Parameters

| 파라미터 | 타입 | 필수 | 설명 |
|---|---|---|---|
| `status` | `VoteStatus` | X | `ATTEND` / `PENDING` / `ABSENT` — 지정 시 `votes[]`를 해당 status로 필터링. 미지정 시 전체 반환. `total`·`attend`·`pending`·`absent` 카운트는 항상 전체 기준. |

Body 없음.

# Response

## 200 OK

```json
{
  "matchId": 1,
  "total": 12,
  "attend": 8,
  "pending": 3,
  "absent": 1,
  "votes": [
    {
      "playerId": 1,
      "name": "김민준",
      "profileImage": "https://storage.example.com/avatars/1.jpg",
      "status": "ATTEND",
      "votedAt": "2025-07-10T10:00:00"
    }
  ]
}
```

## 401 Unauthorized

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "인증이 필요합니다."
  }
}
```

## 403 Forbidden

```json
{
  "error": {
    "code": "FORBIDDEN",
    "message": "해당 경기에 접근 권한이 없습니다."
  }
}
```

## 404 Not Found

```json
{
  "error": {
    "code": "MATCH_NOT_FOUND",
    "message": "존재하지 않는 경기입니다."
  }
}
```

## 500 Internal Server Error

```json
{
  "error": {
    "code": "INTERNAL_SERVER_ERROR",

```
