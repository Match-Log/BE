# 초대 코드로 팀 가입

HTTP 메서드: POST
HTTP 상태코드: 201 Created, 400 Bad Request, 401 Unauthorized, 404 Not Found, 409 Conflict, 500 Server Error
URL Path (https:// 없으면 FE와 BE 인스턴스 주소): /api/v1/teams/join
버전: V1
분류: Team
엑세스 토큰 필요: O

# Request

## Headers

- `Content-Type: application/json`
- `Accept: application/json`
- `Authorization: Bearer {accessToken}`

## Body

```json
{
  "inviteCode": "HK4829"
}
```

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| inviteCode | string | ✅ | 6자리 초대 코드 |

inviteCode는 팀 생성 시 서버가 자동 생성하며 재발급이 불가합니다.

가입 시 PARTICIPATIONS row가 자동 생성됩니다. (role: PLAYER)

# Response

## 201 Created

```json
{
  "participationId": 1,
  "teamId": 1,
  "teamName": "FC 한강불사조",
  "teamImage": null,
  "playerId": 9,
  "role": "PLAYER",
  "joinedAt": "2025-03-01T00:00:00"
}
```

## 400 Bad Request

```json
{
  "error": {
    "code": "INVALID_REQUEST_BODY",
    "message": "요청 값이 올바르지 않습니다."
  }
}
```

## 401 Unauthorized

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "인증이 필요합니다."
  }
}
```

## 404 Not Found

```json
{
  "error": {
    "code": "INVITE_CODE_NOT_FOUND",
    "message": "유효하지 않은 초대 코드입니다."
  }
}
```

## 409 Conflict

```json
{
  "error": {
    "code": "ALREADY_JOINED",
    "message": "이미 가입된 팀입니다."
  }
}
```

## 409 Conflict → Service 검증

한 선수는 최대 2개 팀까지만 소속될 수 있음

```json
{
  "error": {
    "code": "TEAM_LIMIT_EXCEEDED",
    "message": "최대 2개 팀까지 소속될 수 있습니다."
  }
}
```

## 500 Internal Server Error

```json
{
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "서버 내부에 오류가 발생했습니다."
  }
}
```
