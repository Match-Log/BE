# 팀 전술 저장

HTTP 메서드: PUT
HTTP 상태코드: 200 Ok, 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found, 500 Server Error
URL Path (https:// 없으면 FE와 BE 인스턴스 주소): /api/v1/matches/{matchId}/tactics/?scope=team
버전: V1
분류: Tactic
엑세스 토큰 필요: O

# Request

## Headers

- `Content-Type: application/json`
- `Accept: application/json`
- `Authorization: Bearer {accessToken}`

## Body

(scope = team )

전술 세부 항목은 전부 optional(nullable) — 입력한 항목만 반영됨

```json
{
  "content": "전방 압박 위주로 운영. 빌드업 시 CDM 두 명이 수비 밸런스 유지.",
  "defensiveLineHeight": "HIGH_LINE",
  "defensiveSpacing": "COMPACT",
  "setPieceDefense": "MAN_MARKING",
  "flankDefense": "ZONE_DEFENSE",
  "offsideTrap": true,
  "crossType": "EARLY_CROSS",
  "setPieceAttack": "SHORT_CORNER",
  "possessionStrategy": "POSSESSION_FOCUSED",
  "pressingTrigger": "FRONT",
  "pressingIntensity": 4
}
```

**필드 설명**

| 필드 | 타입 | 값 |
| --- | --- | --- |
| content | string, nullable | 자유 코멘트 |
| defensiveLineHeight | enum, nullable | `HIGH_LINE`(하이라인) / `MID_BLOCK`(미드블록) / `LOW_BLOCK`(로우블록) |
| defensiveSpacing | enum, nullable | `COMPACT`(컴팩트) / `WIDE`(넓음) |
| setPieceDefense | enum, nullable | `MAN_MARKING`(전담마크) / `ZONE_DEFENSE`(지역방어) |
| flankDefense | enum, nullable | `MAN_MARKING`(전담마크) / `ZONE_DEFENSE`(지역방어) |
| offsideTrap | boolean, nullable | 오프사이드 트랩 활용 여부 |
| crossType | enum, nullable | `EARLY_CROSS`(얼리크로스 위주) / `BOX_ENTRY_CROSS`(페널티 박스 진입 후 크로스 위주) / `CUTBACK`(컷백 위주) |
| setPieceAttack | enum, nullable | `SHORT_CORNER`(숏코너) / `DIRECT_SHOT`(직접 슈팅) / `HEADER_TARGET`(헤딩 타겟) |
| possessionStrategy | enum, nullable | `POSSESSION_FOCUSED`(점유율 중시) / `QUICK_COUNTER`(빠른 역습 중시) / `MIXED`(혼합) |
| pressingTrigger | enum, nullable | `FRONT`(전방) / `MIDFIELD`(중원) / `OWN_HALF`(자진영) |
| pressingIntensity | int, nullable | 압박 강도 1~5 |

있으면 수정, 없으면 생성 (Upsert 방식)
