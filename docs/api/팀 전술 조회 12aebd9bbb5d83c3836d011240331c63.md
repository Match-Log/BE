# 팀 전술 조회

HTTP 메서드: GET
HTTP 상태코드: 200 Ok, 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found, 500 Server Error
URL Path (https:// 없으면 FE와 BE 인스턴스 주소): /api/v1/matches/{matchId}/tactics/?scope=team
버전: V1
분류: Tactic
엑세스 토큰 필요: O

# Request

## Headers

- `Content-Type: application/json`
- `Accept: application/json`
- `Authorization: Bearer {accessToken}`

## Body

없음

# Response

## 200 OK

( scope=team 지정 시 , 단일 객체 ) 

team 전술 세부 항목(defensiveLineHeight ~ pressingIntensity)은 값이 없으면 `null`로 응답됨

```json
{
  "tacticId": 501,
  "matchId": 1,
  "scope": "team",
  "playerId": null,
  "content": "전방 압박 위주로 운영. 빌드업 시 CDM 두 명이 수비 밸런스 유지.",
  "defensiveLineHeight": "HIGH_LINE",
  "defensiveSpacing": "COMPACT",
  "setPieceDefense": "MAN_MARKING",
  "flankDefense": "ZONE_DEFENSE",
  "offsideTrap": true,
  "crossType": "EARLY_CROSS",
  "setPieceAttack": "SHORT_CORNER",
  "possessionStrategy": "POSSESSION_FOCUSED",
  "pressingTrigger": "FRONT",
  "pressingIntensity": 4,
  "updatedAt": "2025-07-14T09:00:00"
}
```

**전술 세부 항목 값 목록**

| 필드 | 값 |
| --- | --- |
| defensiveLineHeight | `HIGH_LINE`(하이라인) / `MID_BLOCK`(미드블록) / `LOW_BLOCK`(로우블록) |
| defensiveSpacing | `COMPACT`(컴팩트) / `WIDE`(넓음) |
| setPieceDefense | `MAN_MARKING`(전담마크) / `ZONE_DEFENSE`(지역방어) |
| flankDefense | `MAN_MARKING`(전담마크) / `ZONE_DEFENSE`(지역방어) |
| offsideTrap | boolean |
| crossType | `EARLY_CROSS`(얼리크로스 위주) / `BOX_ENTRY_CROSS`(페널티 박스 진입 후 크로스 위주) / `CUTBACK`(컷백 위주) |
| setPieceAttack | `SHORT_CORNER`(숏코너) / `DIRECT_SHOT`(직접 슈팅) / `HEADER_TARGET`(헤딩 타겟) |
| possessionStrategy | `POSSESSION_FOCUSED`(점유율 중시) / `QUICK_COUNTER`(빠른 역습 중시) / `MIXED`(혼합) |
| pressingTrigger | `FRONT`(전방) / `MIDFIELD`(중원) / `OWN_HALF`(자진영) |
| pressingIntensity | int, 1~5 |

( scope 생략, 전체 조회 시 배열 ) 

player scope(개인 전술)는 기존과 동일하게 `content`만 사용하며 team 전술 세부 항목은 포함되지 않음

```json
[
  {
    "tacticId": 501,
    "matchId": 1,
    "scope": "team",
    "playerId": null,
    "content": "...",
    "defensiveLineHeight": "HIGH_LINE",
    "defensiveSpacing": "COMPACT",
    "setPieceDefense": "MAN_MARKING",
    "flankDefense": "ZONE_DEFENSE",
    "offsideTrap": true,
    "crossType": "EARLY_CROSS",
    "setPieceAttack": "SHORT_CORNER",
    "possessionStrategy": "POSSESSION_FOCUSED",
    "pressingTrigger": "FRONT",
    "pressingIntensity": 4,
    "updatedAt": "..."
  },
  { "tacticId": 502, "matchId": 1, "scope": "player", "playerId": 9, "content": "...", "updatedAt": "..." }
]
```

## 400 Bad Request

```json
{
  "error": {
    "code": "INVALID_REQUEST_BODY",
    "message": "요청 값이 올바르지 않습니다."
  }
}
```

## 401 Unauthorized

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "인증이 필요합니다."
  }
}
```

## 403 Forbidden

```json
{
  "error": {
    "code": "FORBIDDEN",
    "message": "개인 전술/피드백 작성 권한이 없습니다. (MANAGER만 가능)"
  }
}
```

## 404 Not Found

```json
{
  "error": {
    "code": "MATCH_NOT_FOUND",
    "message": "존재하지 않는 경기입니다."
  }
}
```
