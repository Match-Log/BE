# 팀 전술 조회

HTTP 메서드: GET
HTTP 상태코드: 200 Ok, 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found, 500 Server Error
URL Path (https:// 없으면 FE와 BE 인스턴스 주소): /api/v1/matches/{matchId}/tactics/?scope=team
버전: V1
분류: Tactic
엑세스 토큰 필요: O

# Request

## Headers

- `Content-Type: application/json`
- `Accept: application/json`
- `Authorization: Bearer {accessToken}`

## Body

없음

# Response

## 200 OK

( scope 지정 시 , 단일 객체 ) 

```json
{
  "tacticId": 501,
  "matchId": 1,
  "scope": "team",
  "playerId": null,
  "content": "전방 압박 위주로 운영. 빌드업 시 CDM 두 명이 수비 밸런스 유지.",
  "updatedAt": "2025-07-14T09:00:00"
}
```

( scope 생략, 전체 조회 시 배열 ) 

```java
[
  { "tacticId": 501, "matchId": 1, "scope": "team", "playerId": null, "content": "...", "updatedAt": "..." },
  { "tacticId": 502, "matchId": 1, "scope": "player", "playerId": 9, "content": "...", "updatedAt": "..." }
]
```

```json
  }
}
```
