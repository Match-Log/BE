# 팀 정보 수정

HTTP 메서드: PATCH
HTTP 상태코드: 200 Ok, 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found, 500 Server Error
URL Path (https:// 없으면 FE와 BE 인스턴스 주소): /api/v1/teams/{teamId}
버전: V1
분류: Team
엑세스 토큰 필요: O

# Request

## Headers

- `Content-Type: application/json`
- `Accept: application/json`
- `Authorization: Bearer {accessToken}`

## Body

```json
{
  "name": "FC 한강불사조",
  "teamImage": "https://storage.example.com/logos/team1.jpg",
  "region": "서울 마포구",
  "foundedYear": 2020,
  "homeGround": "한강공원 풋살장"
}
```

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| name | string | ❌ | 팀 이름 |
| teamImage | string | ❌ | 팀 이미지 URL |
| region | string | ❌ | 활동 지역 |
| foundedYear | int | ❌ | 창립 연도 |
| homeGround | string | ❌ | 주 활동 장소 |

# Response

## 200 OK

```json
{
  "teamId": 1,
  "name": "FC 한강불사조",
  "updatedAt": "2025-03-01T00:00:00"
}
```

## 400 Bad Request

```json
{
  "error": {
    "code": "INVALID_REQUEST_BODY",
    "message": "요청 값이 올바르지 않습니다."
  }
}
```

## 401 Unauthorized

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "인증이 필요합니다."
  }
}
```

## 403 Forbidden

```json
{
  "error": {
    "code": "FORBIDDEN",
    "message": "팀 정보 수정 권한이 없습니다. (MANAGER만 가능)"
  }
}
```

## 404 Not Found

```json
{
  "error": {
    "code": "TEAM_NOT_FOUND",
    "message": "존재하지 않는 팀입니다."
  }
}
```

## 500 Internal Server Error

```json
{
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "서버 내부에 오류가 발생했습니다."
  }
}
```
