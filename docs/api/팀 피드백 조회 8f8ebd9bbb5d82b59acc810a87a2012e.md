# 팀 피드백 조회

HTTP 메서드: GET
HTTP 상태코드: 200 Ok, 401 Unauthorized, 403 Forbidden, 404 Not Found, 409 Conflict, 500 Server Error
URL Path (https:// 없으면 FE와 BE 인스턴스 주소): /api/v1/matches/{matchId}/feedbacks/?scope=team
버전: V1
분류: Feedback
엑세스 토큰 필요: O

# Request

## Headers

- `Content-Type: application/json`
- `Accept: application/json`
- `Authorization: Bearer {accessToken}`

Body 없음.

# Response

경기 상태가 FINISHED일 때만 조회 가능.

## 200 OK

```json
{
  "feedbackId": 601,
  "matchId": 1,
  "scope": "team",
  "playerId": null,
  "content": "세트피스 마크 이탈 잦음. 후반 압박 강도 유지 필요.",
  "updatedAt": "2025-07-14T09:00:00"
}
```

## 401 Unauthorized

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "인증이 필요합니다."
  }
}
```

## 403 Forbidden

```json
{
  "error": {
    "code": "FORBIDDEN",
    "message": "해당 피드백에 접근 권한이 없습니다."
  }
}
```

## 404 Not Found

```json
{
  "error": {
    "code": "MATCH_NOT_FOUND",
    "message": "존재하지 않는 경기입니다."
  }
}
```

## 409 Conflict

```json
{
  "error": {
    "code": "MATCH_NOT_FINISHED",
    "message": "종료된 경기에만 피드백을 조회할 수 있습니다."
  }
}
```

## 500 Internal Server Error

```json
{
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "서버 내부에 오류가 발생했습니다."
  }
}
```
