# 프로필 조회

HTTP 메서드: GET
HTTP 상태코드: 200 Ok, 401 Unauthorized, 404 Not Found, 500 Server Error
URL Path (https:// 없으면 FE와 BE 인스턴스 주소): /api/v1/users/{userId}
버전: V1
분류: User
엑세스 토큰 필요: O

# Request

## Headers

- `Content-Type: application/json`
- `Accept: application/json`
- `Authorization: Bearer {accessToken}`

Body 없음.

# Response

## 200 OK — 본인 요청 시

```json
{
  "userId": 1,
  "email": "user@example.com",
  "name": "임준혁",
  "profileImage": "https://storage.example.com/avatars/1.jpg",
  "provider": "LOCAL",
  "playerId": 1,
  "createdAt": "2025-03-01T00:00:00"
}
```

## 200 OK — 타인 요청 시 (계정 정보 제외)

```json
{
  "userId": 1,
  "name": "임준혁",
  "profileImage": "https://storage.example.com/avatars/1.jpg",
  "playerId": 1
}
```

타인 요청 시 email, provider, createdAt은 제외됩니다.

선수 등록을 하지 않은 유저는 playerId가 null로 반환됩니다.

신체정보(키/몸무게/생년월일/선호발/경력)는 여기서 반환하지 않으며, playerId로 `GET /api/v1/players/{playerId}`를 별도 호출해 조회합니다.

## 401 Unauthorized

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "인증이 필요합니다."
  }
}
```

## 404 Not Found

```json
{
  "error": {
    "code": "USER_NOT_FOUND",
    "message": "존재하지 않는 유저입니다."
  }
}
```

## 500 Internal Server Error

```json
{
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "서버 내부에 오류가 발생했습니다."
  }
}
```
