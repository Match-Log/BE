# 피드백 조회

HTTP 메서드: GET
HTTP 상태코드: 200 Ok, 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found, 500 Server Error
URL Path (https:// 없으면 FE와 BE 인스턴스 주소): /api/v1/matches/{matchId}/feedbacks?scope={team | player}
- scope=team: /api/v1/matches/{matchId}/feedbacks?scope=team
- scope=player: /api/v1/matches/{matchId}/feedbacks?scope=player&playerId={playerId}  ← playerId 필수
- scope 생략 (전체 조회): /api/v1/matches/{matchId}/feedbacks
버전: V1
분류: Feedback
엑세스 토큰 필요: O

# Request

## Headers

- `Content-Type: application/json`
- `Accept: application/json`
- `Authorization: Bearer {accessToken}`

Body 없음.

# Response

## 200 OK

( scope = team, 단일 객체 )

```json
{
  "feedbackId": 601,
  "matchId": 1,
  "scope": "team",
  "playerId": null,
  "content": "세트피스 마크 이탈 잦음. 후반 압박 강도 유지 필요.",
  "updatedAt": "2025-07-14T09:00:00"
}
```

( scope = player, 단일 객체 )

```json
{
  "feedbackId": 602,
  "matchId": 1,
  "scope": "player",
  "playerId": 9,
  "content": "전방 압박 타이밍 좋았음. 오프사이드 트랩 대응 개선 필요.",
  "rating": 8,
  "pros": "전방 압박 타이밍이 좋았고 2골 모두 상대 실수를 유도한 결과.",
  "cons": "오프사이드 트랩 대응 미흡. 체력 관리 필요.",
  "tags": ["#득점", "#압박", "#위치선정"],
  "isVisible": true,
  "updatedAt": "2025-07-14T09:00:00"
}
```

( scope 생략, 전체 조회 시 배열 ) 

```java
[
  { "feedbackId": 601, "matchId": 1, "scope": "team", "playerId": null, "content": "...", "updatedAt": "..." },
  { "feedbackId": 602, "matchId": 1, "scope": "player", "playerId": 9, "content": "...", "rating": 8, "pros": "...", "cons": "...", "tags": ["..."], "isVisible": true, "updatedAt": "..." }
]
```

참고: 선수 본인이 조회할 땐 `isVisible: false`인 피드백은 응답에서 제외, 코치/매니저는 `isVisible` 관계없이 전체 조회.

## 401 Unauthorized

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "인증이 필요합니다."
  }
}
```

## 403 Forbidden

```json
{
  "error": {
    "code": "FORBIDDEN",
    "message": "해당 피드백에 접근 권한이 없습니다."
  }
}
```

## 404 Not Found

```json
{
  "error": {
    "code": "MATCH_NOT_FOUND",
    "message": "존재하지 않는 경기입니다."
  }
}
```
