# 회원가입

HTTP 메서드: POST
HTTP 상태코드: 201 Created, 400 Bad Request, 409 Conflict, 500 Server Error
URL Path (https:// 없으면 FE와 BE 인스턴스 주소): /api/v1/auth/signup
버전: V1
분류: Auth
엑세스 토큰 필요: X

# Request

## Headers

- `Content-Type: application/json`
- `Accept: application/json`

## Body

```json
{
  "email": "user@example.com",
  "password": "password123!",
  "name": "임준혁",
  "profileImage": "https://storage.example.com/avatars/1.jpg",
  "provider": "LOCAL"
}
```

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| email | string | ✅ | 이메일 형식 · 5~254자 |
| password | string | ✅ | 8~20자 · 영문+숫자 조합 · 소셜 로그인 시 null |
| name | string | ✅ | 2~50자 |
| profileImage | string | ❌ | 프로필 이미지 URL · nullable |
| provider | string | ✅ | LOCAL / KAKAO · 로그인 수단 |

# Response

## 201 Created

```json
{
  "userId": 1,
  "email": "user@example.com",
  "name": "임준혁",
  "profileImage": null,
  "provider": "LOCAL",
  "createdAt": "2025-03-01T00:00:00"
}
```

## 400 Bad Request

```json
{
  "error": {
    "code": "INVALID_REQUEST_BODY",
    "message": "요청 값이 올바르지 않습니다."
  }
}
```

## 409 Conflict → Service 검증

```json
{
  "error": {
    "code": "EMAIL_CONFLICT",
    "message": "이미 가입된 이메일입니다."
  }
}
```

## 500 Internal Server Error

```json
{
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "서버 내부에 오류가 발생했습니다."
  }
}
```
